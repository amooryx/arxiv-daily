# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by emailing:

**[maintainer-email@example.com]**

Please do not open a public issue. Instead, send a detailed report including:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any proof of concept (PoC) if available

We will review the report promptly and work toward a resolution. Responsible disclosure is appreciated and properly credited.
